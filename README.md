# かおの さかな

顔写真を取り込むと、その顔をのせた人面魚が3Dの水槽を泳ぎまわり、間をあけて話しかけてくるページです。
iPad の Safari で開くことを想定しています。

## つかいかた

1. 「みずそうを ひらく」を押す（iPad は一度タップしないと音が鳴らないため、この画面が必要です）
2. 画面右下の小さな丸を 1.2 秒 長押しすると、設定が開きます
3. 「しゃしんを えらぶ」→ 黄色い「め」「くち」の印に顔を合わせる → 「これで いい」

指で動かし、2本の指で たて・よこ を別々に伸ばせます。つまみでも調節できます。

## しゃしん・せりふの あつかい

- 顔の写真、セリフ、セリフの画像、ボイスは、**この端末のブラウザの中（IndexedDB）にだけ保存**します。同じ端末なら、次に開いても残ります
- **どこにも送りません。** ページには、外への送信をブラウザ自身に止めさせる設定（Content-Security-Policy）を入れています。外から取ってくるのは three.js（cdnjs）とフォント（Google Fonts）だけで、こちらのデータは載せません
- 読み上げは、**端末の中で読み上げる声だけ**を使います。ネット経由で読み上げる声（PC の Chrome の Google の声など）は使いません。端末の中の日本語の声が無いブラウザでは、読み上げずに字幕だけを出します
- 設定画面の「データを けす」で、この端末に保存したものを全部消せます
- iPad の Safari は、しばらく（7日ほど）開かないと、サイトの保存データを消すことがあります。ホーム画面に追加して使うと消えにくくなります

## なかみ

- `index.html` 1ファイルだけで動きます（three.js を CDN から読み込みます）
- 顔は平らな写真を貼るのではなく、鼻・眉・頬の凹凸をもつ立体に投影しています
- 体はうろこの凹凸つき。ひれは ひれすじ のある膜
- 泳ぎ方は16通り。話すときは、ガイドの口の線のところで唇が少し開き、奥の黒い空洞が見えます
- 鼻の高さと、口のたての開き方は、設定のつまみで変えられます
- 顔写真を決めるたびにくじを引きます。**10%で大きな手**が生え、残りはいつもの魚です
- セリフは設定画面で最大10個まで書けます。10秒に1回、上から順に話します
- セリフごとに「よみあげ」か「ボイス」（端末の音声ファイル）を選べます。ボイスのときは、音声の大きさに合わせて口が動きます
- セリフごとに端末の画像を付けると、話しているあいだ（ボイスならその長さだけ）右上に金の枠で表示します（少し透けて、フェードで出入り）
- BGM は `bgm.mp3` を流します。無いときは、その場で合成した音を流します
- まわりには水草の株、岩、小魚の群れがいます
- 水のなかの BGM が流れます（音源ファイルは持たず、その場で合成しています）
- 設定で「こえ」「じまく」「おんがく」「あわの おと」「うごき」を切れます

## 必要なもの

WebGL が動くブラウザ。読み上げには、端末に日本語の音声が入っている必要があります。
